# Robinhood SupportInfo — GitHub / Vercel Static Site

This package contains the uploaded static HTML landing page prepared for deployment as a simple static website.

## Files
- `index.html` — main landing page
- `privacy.html` — privacy page referenced by the landing page
- `terms.html` — terms page referenced by the landing page

## Deploy to GitHub
1. Create a new GitHub repository.
2. Upload all three HTML files and this README.
3. Commit the files.

## Deploy to Vercel
1. Import the GitHub repository into Vercel.
2. This is a static HTML project; no build command is required.
3. Leave the output directory as the project root.
4. Deploy.

## Before going live
The uploaded source currently uses `https://example.com/` as its canonical URL. Replace that value in `index.html` with your actual production domain after the domain is known. The source also contains a placeholder toll-free phone number (`+10000000000`); replace it with your real number if the call buttons are intended to be active.

## Important
The landing page identifies itself as independent and not affiliated with Robinhood Markets, Inc. Keep that disclosure accurate and do not present the site as an official Robinhood website.
